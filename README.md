# Machine Learning Forecasting of Satellite-Derived NO2 over Shanghai

This project predicts daily NO2 concentrations over Shanghai using satellite data from Sentinel-5P and meteorological data from ERA5-Land. Several models are tested, including Linear Regression, LSTM, 1D-CNN, and L-TAE.

## Requirements

Install Python (>=3.8) and the following libraries:

pip install numpy pandas matplotlib scikit-learn torch

You also need access to Google Earth Engine.

## Running the Code

Run the notebook:

pipeline.ipynb

## Results

The notebook automatically evaluates prediction performance. Check the results at the end of the notebook.
